# 诊断与错误码

Luna 的诊断使用以下稳定格式：

```text
error[ownership/OWN0001]: use after move of 'buffer'
```

前半部分保留产生错误的阶段，后半部分是可用于编辑器集成、CI 断言和文档检索的稳定编号。错误信息、源码片段和 `help:` 可以随着诊断改进而扩充；已发布的核心错误码不改变其语义。

| 前缀 | 阶段 | 代表性编号 |
|---|---|---|
| `LEX` | 词法 | `LEX0001`：非法字符 |
| `PAR` | 解析 | `PAR0001`：期望的语法元素缺失 |
| `PKG` | 包加载 | `PKG0001`：输入不可读；`PKG0003`：包名不一致 |
| `SEM` | 语义/类型 | `SEM0001`：未定义名称；`SEM0002`：类型约束；`SEM0003`：缺失返回；`SEM0101`：C ABI 边界 |
| `TRT` | trait | `TRT0001`：trait 约束错误 |
| `OWN` | 所有权 | `OWN0001`：move 后使用；`OWN0002`：free 后使用；`OWN0003`：借用冲突；`OWN0004`：线性值未消费；`OWN0101`：GPU event/in-flight；`OWN0201`：控制流状态不一致 |
| `CGN` | 代码生成 | `CGN0001`：无效宿主 LLVM IR；`CGN0101`：CUDA；`CGN0102`：ROCm/AMDGPU |

每个阶段的 `9999` 是稳定的通用兜底码，表示该错误尚未属于公开的细分类。新增细分类必须同时附带回归测试和本文档更新。
